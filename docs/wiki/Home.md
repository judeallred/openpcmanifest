# OpenPCManifest user guide

OpenPCManifest shows exactly what's inside your Windows PC and answers the questions you usually open a tool like this to ask: *Can I add more RAM? Is there a free slot for that card? Is this drive dying? Can this PC run Windows 11?*

It's free, open source (MIT), a single portable `.exe`, and it never connects to the internet.
