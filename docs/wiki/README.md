# Wiki source

These files are the source for the project's
[GitHub wiki](https://github.com/judeallred/openpcmanifest/wiki), which the app's
**Help → User guide** opens. Edit them here in a pull request, then copy the changed
page into the wiki (each file name is the page name, with `-` for spaces). Pages other than
Home start without a top-level heading, because the wiki shows the page name as the title.
